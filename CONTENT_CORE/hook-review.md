# Hook review — 250 ประโยค

มี **250 ประโยค** ใน `HOOK_LIBRARY` ที่ `02-master-prompt-template.js`:

- **1–200** ชุดเดิม (หมวดละ 50: FOMO / AUTHENTIC / OBSESSION / CURIOSITY)
- **201–250** เพิ่มใหม่ — 201–213 FOMO, 214–226 AUTHENTIC, 227–238 OBSESSION, 239–250 CURIOSITY

ไฟล์ `hook-review.csv` ใช้ตรวจ **ประโยคโคลน** (คอลัมน์โคลนจำกัดไม่เกิน 51 ตัวอักษร และต้องไม่ซ้ายกับประโยคเดิม) และติ๊ก **ผ่าน** / **ไม่ผ่าน**

## ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | รายละเอียด |
|------|-------------|
| `hook-review.csv` | ตาราง 250 แถว: ลำดับ, หมวด, ประโยคเดิม, ประโยคโคลน, ผ่าน, ไม่ผ่าน |
| `02-master-prompt-template.js` | นิยาม `HOOK_LIBRARY` ต้นทาง (รวม 250 รายการ) |
| `02b-hook-library.js` | สำเนา `HOOK_LIBRARY` ชุดเดียวกัน (ถ้าโปรเจกต์ import จากไฟล์นี้) |

เปิด `hook-review.csv` ใน Google Sheets หรือ Excel เพื่ออ่านและติ๊กคอลัมน์ **ผ่าน** / **ไม่ผ่าน** ตามเกณฑ์ของทีม
