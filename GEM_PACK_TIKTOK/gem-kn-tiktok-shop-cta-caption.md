# Knowledge: TikTok Shop — CTA, Caption, JSON Output + Hook Library
> ดึงจาก sidepanel.js (CONTENT_PROMPT_*) และ 02-master-prompt-template.js (HOOK_LIBRARY)
> ใช้เป็น Knowledge ใน Gem — ยึดกฎในไฟล์นี้เป็นหลักสำหรับ output ที่จะโพสต์จริงบน TikTok

---

## 1. โหมด Output (เลือก 1 โหมดต่อครั้ง)

| โหมด | ใช้เมื่อ | Fields ที่ต้องส่งกลับ |
|------|----------|----------------------|
| Normal (8 วิ) + มีข้อความ | คลิปสั้น มีพาดหัว H1/H2 | `h1, h2, caption, speech, cta, hookId` |
| Extend (16 วิ) + มีข้อความ | คลิปยาว มีพาดหัว H1/H2 | `h1, h2, caption, speech, speech2, cta, hookId` |
| Normal (8 วิ) ไม่มีข้อความ | คลิปสั้น ไม่มีพาดหัว | `caption, speech, cta, hookId` |
| Extend (16 วิ) ไม่มีข้อความ | คลิปยาว ไม่มีพาดหัว | `caption, speech, speech2, cta, hookId` |

Output ต้องเป็น **JSON เท่านั้น** ห้ามส่ง plain text ปน

---

## 2. กฎ H1 / H2

- **H1:** คำสั้นโดดเด่น เช่น "1 แถม 1", "ลดราคา 50%", "ของมันต้องมี"
- **H2:** ชื่อสินค้าหรือจุดเด่นสั้นๆ
- ห้ามใช้คำพาดหัวซ้ำกับที่เคยใช้แล้วในชุดเดียวกัน

---

## 3. กฎ CTA (Call to Action) — บังคับเข้มงวดมาก

- ความยาวสูงสุด: **30 ตัวอักษร** (นับก่อนส่งทุกครั้ง)
- **ห้าม:** emoji และสัญลักษณ์พิเศษทุกชนิด (%, &, #, @, !, ?, ดอกจัน ฯลฯ)
- **ใช้ได้เฉพาะ:** ภาษาไทย, ภาษาอังกฤษ, ตัวเลข, ช่องว่าง
- **ห้ามคำเหล่านี้ใน CTA:**
  - ส่งฟรี
  - ฟรีค่าส่ง
  - ส่งฟรีทั่วไทย
  - รับประกันคืนเงิน
  - ของแท้ 100%

**ตัวอย่าง CTA ที่ผ่าน:**
- สั่งเลยวันนี้
- ของดีราคาถูก
- กดสั่งซื้อเลย
- ดูเพิ่มเติม
- กดตะกร้าได้เลย
- ลิงก์ในไบโอ

---

## 4. กฎเพศ (บังคับทุกฟิลด์ speech)

- ตัวละครผู้ชาย → ใช้ **ครับ / นะครับ** เท่านั้น ห้ามใช้ค่ะ/นะคะ
- ตัวละครผู้หญิง → ใช้ **ค่ะ / นะคะ** เท่านั้น ห้ามใช้ครับ/นะครับ
- ห้ามสลับเพศกลางสคริปต์เด็ดขาด
- speech และ speech2 ต้องใช้เพศเดียวกันและต่อเนื่องกัน

---

## 5. กฎ Caption

- ดึงดูดใจ มี emoji ที่เหมาะสม และ hashtag
- เขียนเหมือนคนพิมพ์เอง ไม่ฟังดูโฆษณาแข็ง
- ห้ามคำต้องห้ามทุกชนิด (ดูรายการเต็มใน `gem-kn-forbidden-phrases.md`)
- ถ้าสินค้าเกี่ยวกับสุขภาพ/ความงาม: ต้องมีบรรทัด "ผลลัพธ์ขึ้นอยู่กับสภาพผิว/ร่างกายของแต่ละบุคคล" ต่อท้าย caption

## 7. ตัวอย่าง Output JSON ที่ถูกต้อง

### Normal Mode (8 วิ + มีข้อความ)
```json
{
  "h1": "ลดราคา 50%",
  "h2": "ครีมบำรุงผิวสูตรเข้มข้น",
  "caption": "แค่ทาทุกคืน ผิวดูดีขึ้นสังเกตได้เลยนะ 🌙✨ #สกินแคร์ #ของมันต้องมี #ผิวสุขภาพดี #TikTokShop",
  "speech": "ใช้มาสองสัปดาห์แล้วค่ะ ผิวนุ่มขึ้นชัดเลย คนในบ้านทักว่าหน้าดูสดใสขึ้นมากเลยนะคะ",
  "cta": "กดสั่งซื้อเลย",
  "hookId": 55
}
```
