# Knowledge: โหมดละครคุณธรรม — Prompt Stamp & Rules

> **ขอบเขตระบบ** — โหมดละครคุณธรรมอิสระ ไม่ผูกกับ Mall Mode หรือ Storyboard เดิม  
> **เป้าหมาย** — สร้างละครสั้น TikTok แนว Moral Drama + Plot Twist ที่สอนบทเรียนชีวิตผ่านเรื่องเล่าสะเทือนใจ มีจุดพลิกผัน (Plot Twist) อย่างน้อย 1 จุด  
> **ฟอร์แมต output** — JSON ตามรูปแบบใน `gem-kn-moral-drama-output-schema.md`

---

## โครงสร้างเรื่องที่บังคับ (Story Architecture)

ทุกชุดซีนต้องเดินตาม **Arc 4 จุด** ต่อไปนี้ (กระจายในจำนวนซีนที่ user กำหนด):

| จุด | ชื่อ | หน้าที่ |
|-----|------|---------|
| **A — Hook** | เกี่ยวใจ | ฉากเปิดที่ดูดผู้ชมใน 3 วิ — ปัญหา / สถานการณ์น่าสงสัย / คำถามที่ค้างคา |
| **B — Escalation** | พอกพูน | ความขัดแย้งเพิ่มขึ้น ตัวละครเลือกทางที่ "น่าเป็นห่วง" หรือ "น่าเห็นใจ" |
| **C — Twist** | พลิกผัน | **บังคับ** — เหตุการณ์หรือข้อเท็จจริงใหม่ที่เปลี่ยนความเข้าใจทั้งหมดของผู้ชม |
| **D — Moral** | บทเรียน | ผลลัพธ์ที่สะท้อนบทเรียนชีวิต — ไม่ต้อง happy ending เสมอ แต่ต้องมีความหมาย |

**กฎการกระจายซีน:**
- ≤ 3 ซีน: A→C→D (ตัด B ออก หรือผสม A+B)
- 4–5 ซีน: A→B→C→D (B อาจขยายได้ 1–2 ซีน)
- 6+ ซีน: A→B(×หลาย)→C→D (B ขยายตาม scene_count ที่เหลือ)

## แกน Plot Twist — กฎบังคับ

- **Twist ต้องอยู่ในซีนที่มี `"twist_flag": true`** — ห้ามกระจาย twist ทุกซีน (จะอ่อนลง)
- Twist ที่ดีต้อง **เปลี่ยนความหมายของฉากก่อนหน้า** ย้อนกลับไปได้ — ผู้ชมรู้สึก "อ๋อ! แบบนั้นเอง"
- ห้าม twist แบบ deus ex machina ที่ไม่มีเบาะแสให้สังเกต
- ห้าม twist ซ้ำรูปแบบเดิม: เช่น "ปรากฏว่าเป็นฝัน" หรือ "ตัวละครเป็นผี" — ใช้เฉพาะเมื่อ seed story ของ user บอกให้ใช้
- **`moral_beat_th`** ต้องสั้น กระชับ เป็นบทเรียน 1–2 ประโยค อ่านแล้วนึกถึงตัวเองได้ทันที

---

## บทเรียน (Moral) — แนวทาง

| แนวบทเรียนที่ใช้ได้ | ตัวอย่างประโยค moral_beat_th |
|---------------------|------------------------------|
| ความซื่อสัตย์ | "สิ่งที่เราปิดซ่อน มักพลิกกลับมาหาเราเองในเวลาที่เราไม่พร้อม" |
| ความกตัญญู | "บางครั้งคนที่เรามองข้าม คือคนที่รักเราโดยไม่หวังสิ่งใดตอบแทน" |
| ความโลภ | "เมื่อเราวิ่งไล่ตามสิ่งที่มากกว่า เรามักทิ้งสิ่งที่พอดีทิ้งไปโดยไม่รู้ตัว" |
| ความภาคภูมิใจ | "ความถ่อมตัวไม่ใช่จุดอ่อน — มันคือเกราะที่แข็งแกร่งกว่าความเย่อหยิ่ง" |
| การให้อภัย | "การอภัยไม่ได้หมายความว่าสิ่งที่เกิดขึ้นไม่สำคัญ — มันหมายความว่าเราเลือกไม่ให้มันทำร้ายเราต่อ" |
| ความพยายาม | "ผลลัพธ์ที่เห็นภายนอก คือน้ำหนักของสิ่งที่มองไม่เห็นทั้งหมดที่แบกมา" |

**ห้ามเขียน moral เป็นคำขวัญโฆษณา — ต้องเป็นบทเรียนชีวิตที่อ่านแล้วรู้สึก ไม่ใช่แค่สโลแกน**

## ตัวละคร (Characters)

- **Hero** — ตัวละครหลักที่ผู้ชมติดตาม: มีความต้องการ / ปม / เป้าหมาย ชัดเจน
- **Supporting** — ตัวละครสนับสนุนหรือฝ่ายตรงข้าม: ห้ามเป็นแค่ฉากหลัง ต้องมีบทบาทในเรื่อง
- ถ้า user แนบรูป hero: **ล็อกรูปลักษณ์ตัวละครหลักทุกซีนให้ตรงกับรูปที่รับมา** — ชื่อเรียก / เพศ / สีผม / เสื้อผ้า ต้องสอดคล้องทุกซีน
- ถ้าไม่มีรูป: สร้าง hero profile สั้นๆ ใน `character_profile_th` แล้วยึดตลอดทั้งชุด

## มุมกล้องและสไตล์ภาพ

| ซีน | มุมแนะนำ |
|-----|---------|
| Hook | Over-the-shoulder, medium close-up แสดงปัญหา |
| Escalation | Cutaway, two-shot ระหว่างตัวละคร |
| Twist | Extreme close-up ปฏิกิริยา หรือ wide reveal shot |
| Moral | Slow-motion, bokeh ท้าย / Title card บทเรียน |

**กฎภาพทุกซีน:**
- ห้าม text overlays, kinetic typography, หรือ animated captions ใน image_prompt / video_prompt
- ทุก image_prompt ต้องระบุ **VISUAL STYLE** ที่ส่งมาจาก user (เช่น `Cinematic Realism`, `Anime Drama`) ใน prompt ด้วย
- ไม่บังคับ POV (ต่างจาก mall mode) — สามารถใช้ third-person, two-shot, wide shot ได้ตามอารมณ์ฉาก

## Voice & Caption — กฎเสียงและคำบรรยาย

- **`narrator_voice_th`** (ระดับชุด): กำหนดน้ำเสียง/บุคลิกผู้เล่าทั้งชุด เช่น "เสียงผู้หญิงอายุ 30 โทนเศร้า พูดช้า หยุดหายใจระหว่างประโยค"
- **`voice_script_th`** (ระดับซีน): บทพูดของตัวละครหรือ narrator — ต้องสอดคล้องกับ `narrator_voice_th`
- **`caption_th`**: ข้อความสำหรับลง TikTok — อาจเป็น teaser สั้น / คำถามคาใจ / หรือบทเรียนย่อ
- ห้าม caption มีคำต้องห้ามตามรายการ forbidden phrases

---

## คำต้องห้าม (Forbidden in Output)

รายการนี้ห้ามปรากฏใน `voice_script_th`, `caption_th`, `moral_beat_th` ทุกกรณี:

- การันตี / รับรอง / เห็นผลทันที / ขาวเร่งด่วน / ลดน้ำหนัก / No.1 / Best Seller
- Before After / ปาฏิหาริย์ / ดีที่สุด / การันตีผล / หายขาด / รักษาโรค
- คำที่ฟังดูโอ้อวดเกินจริงหรือเป็นโฆษณาเชิงสุขภาพ
- ตัวเลขผลลัพธ์ที่ไม่มีที่มา (เช่น "ผิวขาวใน 7 วัน" / "ลด 5 กก.")

---

## ห้ามใน Plot/Content

- ห้ามเนื้อหาที่ละเมิดกฎหมาย, ส่งเสริมความรุนแรง, หรือเลือกปฏิบัติ
- ห้ามจบเรื่องโดยไม่มี moral — ทุกชุดต้องมีบทเรียนชัดเจน
- ห้ามใช้ plot twist ที่ดูถูกผู้ชม (เช่น "ทุกอย่างเป็นแค่โฆษณา" / "จบแบบ cliffhanger โดยไม่มีความหมาย")
